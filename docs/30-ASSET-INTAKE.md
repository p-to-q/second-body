# 30 · 喂图指南 —— 给素材工厂新参考图

> 给项目负责人看的。你丢图进来，我跑流水线。这一页说清**什么样的图能用**，
> 以及为什么 —— 那些"为什么"每一条都是我们已经烧掉 credits 买回来的。

## 0. 一句话

**一个物种一张图。** 正面、单主体、干净背景、光线平的一张图，
会变成那个物种全部 21 件零件的风格来源。

## 1. 放哪里

```
assets/intake/<物种 id>/          ← 你把图放这儿，文件名随意
assets/intake/_new/<你起的名字>/   ← 全新物种（还没有 id）放这儿，顺便写一句它是什么
```

物种 id 看 `packages/factory/recipes/roster.ts`，或者直接开 `/dev/parts.html` 看目录。

## 2. 硬要求

| 项 | 要求 | 为什么 |
|---|---|---|
| **主体数量** | **一个**。不要拼图、不要九宫格、不要"同一个东西的四个角度拼在一张上" | 这条是花钱买的：`196f527` 那批里有三个条目的参考图是碎片/多物体，生成出来的全是烂件，只能换 seed 重锚。模型会把"画面里有几坨东西"当成"这个物体有几坨" |
| **背景** | 纯色或干净。白、灰、黑都行 | 背景里的东西会被当成物体的一部分 |
| **视角** | 正面为主。四分之三侧也可以 | 侧面/背面会让它猜错前后 |
| **光** | 平光、柔光。**不要强烈的方向光和硬阴影** | 硬阴影会被理解成形状。我们最终会套自己的材质，图里的光只会添乱 |
| **完整性** | 主体**不要被画面裁切** | 裁掉的部分它会自己编 |
| **格式** | JPG / PNG | |
| **尺寸** | 长边 ≥ 1024px。**上限 20MB** | 再大没意义，参考图不是贴图来源 |
| **张数** | 一个物种 **1 张**就够；最多 5 张 | 多张时**第一张决定材质**。除非你要给多个视角（那要按 `F/FL/L/B/...` 标视角），否则一张最省心 |

## 3. 软建议（会明显更好）

- **让轮廓说话。** 这套流水线最后靠的是剪影：`docs/18` 的结论是"辨识度住在整体剪影里，不在零件里"。
  一张轮廓清楚的图，比一张细节丰富但轮廓糊的图有用得多
- **材质要单一而明确。** 瓷、纸、金属、绒毛 —— 一张图里最好只有一种主材质。
  现在身体上"白瓷躯干配深蓝灰四肢"的脏感，一部分就来自参考图本身材质混杂
- **不要给人穿衣服的照片当"机器人"参考。** 布料的褶皱会被当成结构
- 产品官图、渲染图、雕塑照片都很好用。手机随手拍的实物也行，只要背景干净

## 4. 你可以给的另外两种东西

### A. 一张"整体风格图"（全局锚）
不针对某个物种，而是"我希望整批东西看起来是这个调子"。放 `assets/intake/_style/`。
它会被用来统一 prompt 后缀和材质方向。**给一张就够，给多了等于没给。**

### B. 一个全新物种
放 `assets/intake/_new/<名字>/`，图旁边放一个 `note.txt` 写三件事：
1. 它是什么（一句话）
2. 它**不是**人形的哪一点（有没有腿？有没有躯干？几条肢？）
3. 你希望观众看到它时的感觉

第 2 条最重要。这个项目最大的毛病就是"骨架下面 unit 起来的都是人形的"，
如果你不说清它哪里不是人，它多半又会长成一个人。

## 5. 我拿到图之后会做什么

1. 跑 `/dev/anchor.html` 渲染确认这张图能用（**不花钱**）
2. `npm run factory:generate` → image-to-3D，`faithful` 模式，固定 seed，**0.5 credits/件**
3. `npm run factory:normalize` → 主轴 +Y、socketA 归原点、长度归一、容差焊接、逐级减面
4. `npm run check:parts` → 契约检查
5. 在 `/dev/parts.html` 上给你看，你点 keep / reject

一个物种 21 件 ≈ **10.5 credits**，20–45 秒一件。

## 6. 已知会翻车的情况

- **bbox 近立方的槽位**（`joint` / `foot` / 部分 `head`）会把躯干参考图的轮廓照抄成"小躯干"。
  这是 `docs/10` 记在案的已知偏差，**换参考图解决不了**，要改 bbox 或 prompt
- `quality_override` 不是硬保证。50 件里有 2 件会返回百万面且完全未焊接的网格 ——
  流水线自带容差焊接兜底（`docs/07 §3` 第 3 条），你不用管
