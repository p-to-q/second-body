# 51 · 收口清单 —— 第零步之前所有诉求，一条一条过

> 2026-09-14。作品负责人："这是我们做第零步之前最后一个需求了，把之前所有的需求都统筹成一个 checklist 去过，
> 做完、收尾、合到 main、整体没问题了，再往下移。"
>
> 规矩：每一条写**谁提的诉求（原话要点）→ 落在哪 → 怎么验的 → 状态**。
> 状态只有四种：✅ 做完且验过 · 🟡 做完但只在无头环境验过（缺真人 / 真摄像头 / 真 GPU）· ⏳ 在跑 · ⛔ 明确不做或暂缓（写理由）。
> 最后一次整体验证的结果写在文末 §Z，没有 §Z 的那一刻这份清单就还没收口。
