# 26 · 作品标准 —— 拿参考图谱的尺子量自己

> 参考图谱给了一条判据：**让模型至少承担一种不可替代的角色**。
> 这份文档拿它和评审的四个维度逐条量我们自己，然后决定改什么。
> 与 `docs/25-COMPLETENESS.md` 配合读：那份量"做完了没"，这份量"值不值得做"。

## A. 五种不可替代的角色，我们占了几种

> **2026-09-13 复核。** C1 落地了 —— 慢回路两端接通、血统池跨会话持久（靶场实测：
> 第二次运行抽到了第一次留下的那件）。这张表因此要重算，但**不是简单地打勾**。

| 角色 | 我们现在 | 差在哪 |
|---|---|---|
| **有状态**（记住上一位观众） | 🟡 机制成立 —— `lineage.json` 记下 session／时间／物种／槽位，跨会话持久 | 只在装置那台机器上；网页版是 404 |
| **有欲望**（会接受/抵抗/误解） | 🟡 `resist` 让身体抵抗快动作 | 是物理阻尼，不是欲望。**没变** |
| **会被改变**（互动后未来行为真的变） | 🟡 机制成立 —— 前人留下的件进下一个人的候选池，`makeGenome` 照抽 | 同上，现场限定 |
| **制造关系**（人—AI—另一位人） | 🟡 机制成立 —— 你身上那块可能来自一个你没见过的人 | **观众不知道**。见下 |
| **留下后果**（谱系/痕迹/不可逆） | 🟡 机制成立 —— 池子只增不减，有上限但不回退 | **观众不知道**。见下 |

**从"五占零"到"五占零点五"。** 不是三个变成了 ✅ —— 而是三个从"没有机制"变成了"有机制但不可见"。

因为这份文档自己在 §C3 写了一条判据：**后果不可见 = 后果不存在。**
观众站在装置前面，没有任何一个界面告诉他"你身上这块是别人留下的"。
按我们自己的尺子，这三条现在**仍然不成立** —— 它们只是从"要写代码"变成了"要做一页"。

**所以下一件必做的事是 `/lineage`。** 不是再加一个物种，不是再优化一档性能。
机制已经花了两条线做出来，而它现在离"成立"只差一个能看见它的界面。

**唯一真正没有进展的是"有欲望"。** `resist` 是临界阻尼跟踪，它抵抗的是速度不是意图。
这一条不要靠再调参数去凑 —— 要么找到一个真正的机制，要么在自评里一直挂着 🟡。

## B. 四个评审维度的诚实自评

| 维度 | 现状 | 判断 |
|---|---|---|
| **技术表达**（AI 是否有效融入创作并形成独特表达） | AI 只在**离线**做素材 | **最弱。** 一个纹理生成器不叫"融入创作过程" |
| **艺术表达**（独立审美判断与感染力） | 排版系统、物种谱系、形体分类都有立场 | 中上，但**没有被真人看过** |
| **世界观**（AI 时代的新议题） | "你愿意变成哪一种非人"；四个玩法各问一个身份问题 | **最强**，是真命题 |
| **人机共创深度**（人与 AI 共同探索的过程） | 这个项目**本身**就是：一个人编排一队 AI，有契约、有裁决、有代理拒绝造假、有代理推翻代理并给理由 | **被严重低估的资产 —— 它现在藏在 git log 里，没有任何一页展示它** |

## C. 三个决定

### C1 · 慢回路升级成"谱系"，而不是"你的零件" ✅ 机制已落地（2026-09-13）

> 服务端 + 前端两端接通，血统池跨会话持久。**但 `/lineage` 那一页还不存在**，
> 所以按 §C3 的判据，这个决定只完成了一半。见 §A 的复核。

原设计：观众剪影 → Rodin → 一块属于他的零件长在身上 → 他走了，零件消失。
**新设计：那块零件不会消失，它进入物种库。**

```
观众 A 留下一块零件 → 存进 assets/lineage/
观众 B 进场时，他的身体**有可能**用到 A 留下的那块
观众 B 看到的档案页上，那块零件写着"由第 137 位观众留下"
```

一次改动同时拿到四个角色：
- **有状态**：库会长大，作品不再每次归零
- **会被改变**：后来者的身体真的因为前人而不同
- **制造关系**：不是人和屏幕，是人—AI—**之前所有的人**
- **留下后果**：谱系是不可逆的沉积

这是把 Pulse Room 的集体记忆和 Galápagos 的谱系，翻译到我们自己的机制里 ——
借的是机制不是外观：我们没有灯阵、没有脚踏选择、没有交配突变。

### C2 · 人机共创的过程要被展示，不是藏在 git log 里

这个项目有一份**别的队大概率没有**的东西：一份真实的人机协作档案。
不是"我用 AI 写了代码"，而是：

- 一套写明的编排契约（`docs/15`），包括**编排者自己犯的错**（P20：编排者的错会被乘以并行度）
- 代理**拒绝造假**的记录（没有真人就不编 U1/U2 的数；坏 anchor 上不再花 credits）
- 代理**推翻代理**并给出理由（升档脉冲从 +108% 改回规格的 +8%，因为提曝光会把背景一起抬起来）
- 代理**报告契约错误而不是绕过**（`handL`/`handR` 那次是编排者写错了验收）
- 十条带故事的原则（P11–P20）—— **没有故事的原则活不过三天**

这些应该有一页。它不是"技术文档"，它是作品的一部分：
**人和 AI 怎么一起做决定、怎么互相纠正、怎么在不确定时停下来问。**

### C3 · 每一页都要有存在的必要

| 页 | 它回答什么问题 | 没有它会怎样 |
|---|---|---|
| `/` 入口 | 这是什么？我要做什么？ | 观众不知道该站哪 |
| `/about` 陈述 | 它为什么存在？和 2019 年那件的区别？ | 评委看不懂立场 |
| `/archive` 档案 | 有哪些物种？它们凭什么不同？ | "23 个物种"只是个数字 |
| `/lineage` 谱系 | 之前的人留下了什么？ | **后果不可见 = 后果不存在** |
| `/making` 共创 | 人和 AI 是怎么一起做出它的？ | 第四个维度白丢 |
| `/poster` 海报 | 一眼说清"多少种可能" | 没有可传播的单帧 |

**凡是不能回答一个问题的页面，删掉。**

## D. 借用的边界（参考图谱的规矩：借机制，至少改三个轴）

我们借 Pulse Room 的"集体记忆"和 Galápagos 的"谱系"。改的轴：

| 轴 | 原作 | 我们 |
|---|---|---|
| 输入媒介 | 心跳传感器 / 脚踏选择 | 全身姿态 |
| 观众角色 | 贡献者 / 选择者 | **被重新制造的人** |
| AI 权限 | 无 AI（Pulse Room）/ 进化算法 | 生成模型决定留下的那块**长什么样** |
| 不可逆规则 | 最旧的被挤掉 | 留下的进入库，可能被后来者穿在身上 |
| 物理痕迹 | 灯阵 | 一个 seed 码 + 一块可下载的 glb |
| 文化语境 | 记忆与消逝 | **具身智能时代"我应该长什么样"** |

六个轴改了六个。

# 这一节是策展判断，不是工程规格

> 上面 A–D 是"拿尺子量自己"。下面 E–G 是**这件作品自己的尺子** ——
> 八条泳道并行推进时，它们各自都在做审美判断，如果没有一条共同的线，
> 结果会是八个局部都不错、合起来不成立的东西。

## E. 那一个问题

所有决定只回答一个问题：

> **一个陌生人站上去，五秒内会不会说"那是我"。**

这不是我发明的判据，它是 `docs/PRD.md §5` 的第一条，也是六条里唯一一条
**只能由人回答**的。其余五条机器都能自动验，所以它们会被优先做完 ——
而作品成立与否恰好全压在这一条上（`docs/25` 记过这个陷阱：
"精力投在可自动验证的层，会持续制造在进展的错觉"）。

**用法**：任何一处改动，先问"这让那五秒更容易发生了吗"，
而不是"这让作品更像一件作品了吗"。两个问题经常给出相反的答案。

举几个实际被这条判据否掉/通过的：

| 改动 | 好看吗 | 五秒判据 | 结果 |
|---|---|---|---|
| 升档时全屏闪光 + 地面冲击波环 | 很抓眼 | 把注意力从身体拉到特效上 | **否掉**（`3b63973`） |
| 末端比根部慢半拍 | 几乎看不出 | 刚体不再像提线木偶，"那是我在动"成立 | **通过** |
| 再加一个物种 | 数字更大 | 不变 | 排到最后 |
| `/lineage` 页 | 一页表格 | "我身上这块是别人的" —— 这是第二个五秒 | **排到最前** |

## F. 物质语言（八条线共用这一套，不要各自发明）

已经被各条线分别定下来、现在统一登记在这里。**新的线照抄，不要重开一套。**

**颜色**：全站只有**一处**用颜色承担语义 —— 成立用强调色、不成立用警示色，
其余一律灰阶。一个页面上出现第二种语义色，就是有人在用颜色解决排版问题。

**排版**：grotesk 的规矩 —— **大字号收紧、小字号放开**（h1 −0.02em，全大写标签 +0.08em）。
中文为主、英文为辅，**并置不切换**。

**形体**：形上不是人，动上是人。
物种靠**整体剪影**辨识，不靠零件（`docs/18`）—— 所以换物种要换身体方案，不是换涂装。

**动作**：末端比根部慢半拍；静止时有呼吸。刚体做不出"弯"，
但一串各自延迟不同的刚体看起来就是在弯。

**声音**：物质的接触声（木、纸、瓷、布、金属），不要游戏音效、不要上扬的成功音。
**降级必须是静默的** —— 给失败配音效等于告诉全场它坏了。

**反面清单**：不用卡片、阴影、圆角、图标、进度条、toast。
这些是产品界面的语汇，它们会让一件装置读起来像一个 app。

**留白**：大块留白要**故意**，不是没内容。

## G. 诚实的位置只有一处

这一条是纠正，纠正的是我自己。

这个项目的自省一度出现在**每一页的结尾**：护照页"挖不到证据的事没有被写进来"、
共创档案"这一页没有写的"、立场海报"这张海报会过期"、`/about`"这一页不写没做到的事"。
单独看每一句都成立。**放在一起看，它是一种腔调。**

诚实一旦变成可预测的句式，它就不再是诚实，是一个姿态 —— 而且是最容易被识破的那种。
一个每页都自曝一句的作品集，读起来像在提前替自己辩护。

**规矩**：

1. **诚实集中在三处**，不散落：
   `docs/25-COMPLETENESS.md`（内部账本）、立场海报（对外的那一张）、
   `/about` 的状态标记（已实现 / 现场限定 / 规格）。
2. **状态标记本身就是诚实**，不需要再配一段告解。
   `/about` 的慢回路那一栏挂着「现场限定」，那句话已经说完了，不必在页尾再说一遍"我们还差什么"。
3. **其余页面把话说完就停。** 不加"但是我们还没有…"作为结尾。
   一页把它该回答的问题回答清楚，就是它最诚实的样子。
4. **需要认错的时候直接认**，不要把它写成风格。

反过来说，那张会过期的立场海报**应该留着** —— 它是这三处之一，而且它兑现过：
慢回路落地那天它出了第二版。**一处兑现，胜过六处声明。**
