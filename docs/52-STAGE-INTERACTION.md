## 1 · 指针路由：一次拾取决定这一下拖的是什么

- **pointerdown 那一刻做一次 CPU 射线拾取**，不做 GPU 读回（读回会卡一帧，而且测不了）。
  拾取对象是**骨架上的胶囊**：每根骨头 `p0→p1`，半径按槽位宽度（`tuning.ts` 的 `SLOT_WIDTH` × 观测身高缩放）。
  多人（docs/50）时每具伴随身体的胶囊按它的 `dx / dz` 平移；**射线命中最近的那一根**，不管是谁的身体。
- 命中身体 → **拽零件**（§3）；没命中（地面、天幕、背景）→ **转视角**（§2）。
- 只有画布收 pointerdown：控件条、读数、右下角那一列、小屏幕、目录都在画布之上，事件不冒到画布（`pointer-events` 本来就这样分层）。
- `setPointerCapture`：拖出窗口不断；`pointercancel` / `lostpointercapture` 等于松手。
- **一次只认一个指针**：第二个指针按下被忽略，直到第一个松手（不做双指缩放：缩放会让等身不成立，而这件作品没有一个"缩放后回正"的叙事）。
- 滚轮：什么都不做（不 `preventDefault`，页面照常）。

## 2 · 转视角：偏移叠在取景之上，永远不替代它

| 项 | 决定 | 理由 |
|---|---|---|
| 轴心 | 身体（多人时整组）的包围盒中心，高度取 `aim.y` | 转的是"看这个身体的角度"，不是转世界 |
| 左右（yaw） | 无限，按 2π 回绕 | 负责人原话 |
| 上下（pitch） | 夹在 **−10° … +35°**（正 = 从上往下看） | 不钻到地板下；+35° 看得见肩和头顶的零件，又不变成平面俯视图 |
| 手感 | 拖动时 1:1（像素 → 弧度，按画布高度归一化）；松手后按拖动末速度惯性，临界阻尼摩擦 | `core/autoframe.ts` 已有 `stepFollow`（闭式临界阻尼、帧率无关），直接用 |
| 回正 | **6 秒没人碰**，用 1.2 秒临界阻尼回到 0；双击 / Escape 立刻回正；弧线归零（换了一个人）立刻回正 | 装置和网页都是"下一个人从等身开始"；回正本身不能是一次切 |
| 和取景的关系 | 取景（全景 / 中景、docs/49）照旧算出一个相机；轨道是**乘在它外面**的一次绕轴心旋转。yaw = pitch = 0 时相机矩阵逐字等于取景给的那个 | 等身规则只在回正之后成立，而回正之后必须逐字成立（守卫） |
| 减少动态 | 没有惯性，松手即停；回正 0.15 秒 | 和 docs/49 的景别同一条 |
| 调速器 | 不参与：轨道是一次矩阵乘法 | 拾取也是 ≤ 17 × 3 个胶囊，比一帧里别的东西都便宜 |
| 墨色采样 / 角上的字 | 不用管：`stage/ink-sampler.ts` 采的是渲染结果，背景转过去它自己跟着变 | — |
| 现场 | `?kiosk=1` 默认关 | 装置前面通常没有指针；一次误触把等身镜头转歪，没有人会去回正 |

## 3 · 拽零件：受力是一个叠在骨架上的、会衰减的偏移

- **不加物理引擎。** 按下时记住命中的是哪根骨头、命中点在骨头上的位置 `u`，以及那一刻命中点的深度。
  拖动时，目标点 = 指针射线与"过命中点、朝向相机的平面"的交点。
- **作用在哪一步**：在 `remapSkeleton` 之后、`vitality.apply` 之前，对**那一根骨头所在的肢链**做一步受限的 FABRIK
  （手 → 前臂 → 上臂，脚 → 小腿 → 大腿，头 → 颈），链根（肩 / 胯 / 胸）不动，骨长逐字保持。
  放在生命力之前，末端的"甩鞭子"延迟就自然落在被拽的那一段上 —— 读起来是它在受力，而不是被钉住。
- **拽躯干 / 骨盆**：整具身体只平移目标位移的 15%，并且夹在 ±12cm（它是被观众驱动的，不许被拖走）。
- **夹住**：末端最大位移 0.45 m；肘 / 膝不许反折（复用 `refine.ts` 的 `clampFold` 那一条最小折叠角）；任何 NaN → 这一帧不拽。
- **松手**：偏移按临界阻尼弹簧回到 0（ω ≈ 6 /s），**不是一次跳回** —— 回弹本身就是"它是活的"的证据。
- **声音**：抓住那一下复用已有的 `cues.play('pass')`（选择页划过卡片那一声），音量压低；松手不响。克制照 docs/29 §S5。
- **团块 / 点场身体**（没有零件）：命中按骨架胶囊照算，受力改成对那一段的球做同样的偏移（团块读的就是骨架），不退化成转视角。
- **忒修斯换件发生在拖动中**：拖的是**骨头**不是零件实例，所以换件不影响受力；那一格正在碎开也照拽（碎片跟着骨头走）。
- **多人**：拽到谁的身体就作用在谁那一副骨架上（伴随身体的滤波链在 `creature/companions.ts` 里，同一个插入点）。

## 4 · 边界：每条一个决定、一个测试

| 边界 | 决定 | 测试（计划） |
|---|---|---|
| 从零件上开始拖，拖离了身体 | 仍然是拽零件，目标点继续按射线算，位移被夹住 | `core/test/stage-hand.test.ts`「拖出身体」 |
| 指针拖出窗口 | pointer capture 保持；`lostpointercapture` = 松手，偏移回弹 | 同上「丢失捕获 = 松手」 |
| 多个指针 | 只认第一个，其余忽略到它松手 | 「第二个指针被忽略」 |
| 升档重建 / 替换那一下正在进行 | 照拽（拖的是骨头） | 「换件中拖动不抛、偏移仍在」 |
| 团块 / 点场 | 同一套偏移作用在骨架上 | 「没有零件的身体照样受力」 |
| 多人 | 射线命中最近的那一根，不管是谁的 | 「两具身体，命中近的那具」 |

## 5 · 开关与界面

- `?orbit=on|off`、`?pull=on|off`：规矩和 `?framing=` 一样（认不出来当没写过并喊一声）。网页默认 on，现场默认 off。
- 控件表一项：「看起来」组里一个 toggle「手」（关 = 两个都关），热切，不重载。
- 光标：悬停在零件上 `grab`，按住 `grabbing`；悬停在舞台上 `move`。悬停也要拾取 —— 用 rAF 节流到每帧最多一次。
- **不加任何文字提示**（负责人不喜欢冗余提示）。如果现场证据显示没人发现能拖，再考虑一个第一次出现时的极轻的光标变化，不是字。

## 6 · 守卫与取证（先红后绿）

1. 俯仰夹住、左右回绕（`core`）。
2. 回正弹簧：6 秒无输入后单调回到 0、帧率无关（60 步与 20 步落点差 < ε）。
3. 拾取路由：合成射线打中胶囊 = 零件、打空 = 舞台；两具身体取近的。
4. 受力：末端位移夹在 0.45m、骨长逐字保持、肘膝不反折、松手单调衰减到 0。
5. 覆盖层不开始拖动；没有 wheel 监听（扫 `main.ts`）。
6. flags / 控件读回（`control-table.test.ts` 的读回那一条自动覆盖）。
7. 预算不变：拖动和轨道都不建桶（`creature` 的 `stats.buckets` 在一段拖动前后相等）。

取证：`scripts/people/measure.ts` 同一套 raw CDP，`Input.dispatchMouseEvent` 按下 → 移动 → 松开；截
俯仰 +35° / −10° 两张、拽左手到头顶一张、松手 0.5 秒后一张、回正 6 秒后一张（和开拖前逐像素比）。
