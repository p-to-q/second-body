# 23 · SPEC · UI —— 每个场景，每个状态，每个边界情况

> 一条总规矩：**每多一个 UI 元素，都要论证它为什么不该被删掉。**
> 这件作品的气质是影棚，不是仪表盘。观众来看的是那具身体，不是我们的界面。
>
> 第二条：**观众永远不该看见"出错了"。** 所有失败都要降级成一个说得通的画面。

## 0. 视觉语言

> **实现在 `packages/app/src/ui/type.css`，这一节是它的说明。**
> 度量取自 zkm.de 线上 CSS（2026-09-12 实测）：body 1.0rem/400/1.5，
> h1 2.00rem/1.15/600，h2 1.50rem/1.25/600，html 100%→105%。
>
> **字体**：`ZKMSerendipity`（Regular/Medium + Italic，228 KB，`font-display: swap`），
> 出处与授权基础见 `assets/fonts/ZKMSerendipity/NOTICE.md`。
> 回退栈 `Helvetica Neue → Neue Haas Grotesk → Suisse Int'l → Univers → Arial → system-ui`，
> **两种情况下排版度量完全一致**，所以字体没到时不会有回流跳动。
> `?font=system` 可以强制走系统栈，用来确认这一点没骗人。

| | 值 | 理由 |
|---|---|---|
| 底色 | `#0E0F12`（近黑，不是纯黑） | 纯黑在投影上会和关机分不清 |
| 前景文字 | `#9AA0A6`，强调 `#DFE4EA` | 不用纯白：纯白会和身体的高光抢注意力 |
| 强调色 | 取当前条目 `palette` 的 accent | UI 跟着物种走，而不是有自己的品牌色 |
| 字体 | 正文 grotesk 系统栈；**数据/标注用等宽** | 数字要能对齐，这是「档案感」的来源之一 |
| 字号 | 正文 1rem / 小号 0.8125rem / h2 1.5rem / h1 2rem | 三级以上就开始像后台系统 |
| 字距 | h1 −0.02em、h2 −0.01em、全大写标签 +0.08em | grotesk 大字号要收紧、小字号要放开 —— 这套风格最容易被忽略的一半 |
| 文案长度 | 单行 ≤ 14 字，全场景总字数 ≤ 60 | 现场没人会读第二行 |
| 动效时长 | 进 240ms / 出 180ms / 过场 1200ms | 出比进快，符合直觉 |
| 缓动 | 进 `cubic-bezier(.16,1,.3,1)`，出 `cubic-bezier(.4,0,1,1)` | — |
| 边距 | 屏幕安全区 ≥ 48px（投影会切边） | 现场真的会切掉 |

**禁止**：加载转圈、toast、模态框、图标按钮、阴影卡片、圆角面板。
这些都是"应用"的语言，不是作品的语言。

> **2026-09-13 修订：「进度条百分比」从禁止清单里去掉了。**
>
> 原来的判断是对的一半：一个**圆角的、会动的进度条**确实是应用的语言。
> 但它被当成了"任何形式的进度都不许有"，于是几 MB 的冷启动期间观众对着黑屏，
> 而黑屏和「坏了」在观众眼里没有区别 —— 这是整条路径上最容易流失人的一刻。
>
> 现在允许的是**档案的语言**：一条 1px 的细横线 + 一个等宽 tabular-nums 的数字。
> 和选择页那条 30 秒倒计时线、和 `/making` 的坐标栏是同一个构件。
> 仍然禁止的是圆角、渐变、条纹、转圈、"正在加载…"的省略号动画。
> 实现见 `packages/app/src/shell/loading.{ts,css}`，两条硬规矩写在那个文件头里：
> **进度必须来自真实信号**，**没有真信号的地方宁可停住也不许编**。

### 动效的一条硬规矩：入场动效不许决定"看不看得见"

带 `animation-fill-mode: both` 的入场动效，等于把元素的静止态设成 `opacity: 0`，
只有动画跑完才变成 1。而动画**不一定跑**：文档时间线没有推进的页面上
（无头浏览器、被降到后台的标签页）它会停在 `playState: running / currentTime: 0`，
于是那个元素永远透明 —— DOM 在、字在、人看不见，而且控制台一声不吭。
本轮实测踩过一次（`shell/notice.ts` 的那一行）。

所以：**出场动效随便用，入场动效不许承担可见性**。要淡入就让静止态是可见的那一侧。

## S0 · Boot（启动 / 自检）

正常路径：**观众不该看见这个场景**——直接进 S1。

| 边界情况 | 表现 | 为什么这么设计 |
|---|---|---|
| WebGPU 首次 pipeline 编译卡顿（0.5–2s） | 底色，**不显示任何文字**（加载态有 600ms 宽限期，这个尺度上它一帧都不画） | 有文字反而强调"在等" |
| 冷启动 0.6 秒以上 | **加载态**：左下角三档 —— `正在点亮画面` / `正在准备零件` / `正在认识你的身体`，各自一个真实百分比，底下一条 1px 的总进度线 | 观众该知道**现在在等什么**，不只是"还要多久"。一个笼统的百分比说不出前半句 |
| WebGPU 不可用 → WebGL2 回退 | 现场：静默。网页：右下角一行 `降级渲染` 4 秒后淡出（`shell/notice.ts`，2026-09-13 落地）。**在加载态收掉之后才说** —— 说早了会被那一层盖住，等它露出来 4 秒早走完了 | 现场没人能处理这个信息；网页用户可能会换浏览器 |
| `parts.json` 缺失 | 静默用占位几何。**绝不提示"资源加载失败"** | 占位几何是合法的 tier 0 形态，本来就是作品的一部分 |
| 单个 glb 失败 | 该槽位用占位件，其余正常 | 观众看不出少了一件 |
| 冷启动 > 8 秒（慢网） | 加载态底下多一行人话：`再等一下，网有点慢`。20 秒后换成 `还在等。第一次打开要下最多东西，之后会快很多` | 说"超时""重试"是运维的词，观众听到它只会走开 |
| 加载途中发生降级（`sb:degrade`） | 那一行换成 `画面会简单一点，它照样会动起来` | 观众读到的是**结果**，不是"降级"这个词 |
| 冷启动 > 8 秒（慢网，粒子版） | 粒子团缓慢聚拢成人形轮廓（本身就好看） | 把等待变成预告。**未实现** —— 目前慢网上是加载态那三行，不是粒子 |
| 启动真的失败（异常抛到顶层） | 满屏底色 + 居中一行 `稍等一下` + 控制台详情 | 观众看到的是一句人话，不是堆栈 |
| `?selftest=1` | 逐条打勾的检查列表（WebGPU / 摄像头 / 资产 / 回放片段） | **只给我们自己用**，现场开场前跑一遍 |

## S1 · Attract（空场）

一团在地面上缓慢呼吸的粒子。**不是黑屏**——黑屏会让观众以为机器坏了。

| 边界情况 | 表现 |
|---|---|
| 无人 5 分钟 | 降到 30fps，粒子更慢。**画面不熄** |
| 有人经过但没停留（< 0.4s） | 粒子有极轻微的偏转（像被风带了一下），不进 S2 |
| 多人经过 | 同上，只跟面积最大的那个 |
| 现场灯光突变导致追踪闪烁 | `presence` 的 0.4s 滞回吸收掉，不闪进闪出 |
| 连续运行数小时 | 粒子的呼吸相位由累计时间驱动，不会"回到起点"露出循环 |

**文字**：现场无。网页版底部一行 `站到画面里` / 或一个 `打开摄像头` 按钮（见 S0 网页分支）。

## S2 · Choose（选物种）

竖直螺旋上的卡片，远离的溶解成有序抖动。卡片图 = 该条目自己的 anchor 渲染。

| 状态 | 表现 |
|---|---|
| 正常 | 中心卡清晰，两侧渐次模糊 + dither |
| 悬停/聚焦 | 中心卡上方一行：`物种名` + `一句 tagline`，**不超过一行** |
| 选中 | 卡片冲向镜头 → 溶回抖动 → 直接进 S3。**没有确认按钮** |

| 边界情况 | 表现 | 理由 |
|---|---|---|
| 某条目没有 anchor 图 | 用程序化卡片（该物种的几何轮廓在抖动里浮现），**不显示破图** | 破图会立刻毁掉整个气质 |
| 条目被 `clearance` 挡住 | 根本不出现在列表里，螺旋自动收紧 | 不能留空位——空位会被当成 bug |
| 可选条目 < 3 个 | 螺旋退化成横向一排 | 3 个以下的螺旋看起来像坏了 |
| 无 WebGL | DOM 降级列表：**同样的排版语言**（等宽字、同底色、卡片图），不是丑陋兜底 | 降级路径也是作品的一部分 |
| 30 秒无操作 | 最后 5 秒中心卡下方出现极细的进度线，走完自动选中 | 没有倒计时的话，突然跳转会吓到人 |
| 观众在选择中途走开 | 倒计时照走，自动选中，进 S3，然后由 `presence` 自然回落 S1 | 不需要特殊处理 |
| 卡片图还在下载（这一页真正的等待） | S0 的加载态**盖在上面**继续走「正在准备零件」那一档，分母是 anchor 图张数；螺旋一挂上来就立刻让位 | 这一页的等待发生在它自己出现之前，外面拿不到任何信号 —— 所以由它上报（`ChooseOptions.onProgress`，只上报，不改这一页的任何表现） |
| 输入方式 | 触摸滑动 / 鼠标滚轮 / 方向键 / 数字键直选 / 遥控器（映射到方向键） | 现场可能只有遥控器 |
| 条目 > 10 个 | 数字键只映射前 10，其余靠滚动 | 别做分页 |

## S3 · Enter（进场）

卡片溶解 → 身体出现。**这一刻必须无缝**：卡片的抖动直接变成身体的抖动。

| 边界情况 | 表现 |
|---|---|
| 该物种的部件还没加载完 | 先用占位几何成形，真件到货后**逐件淡入替换**，不整体重建、不闪 |
| 摄像头还没就绪 | 身体先以 tier 0 的原始形态站着轻微呼吸，追踪到人后接管 |
| 观众在过场动画中走开 | 动画照常演完，然后 `presence` 走 LEAVING → S1 |
| 过场超过 1.2 秒 | 不允许。资产没到就用占位，**时间不许被资产绑架** |

## S4 · Live（共舞 · 核心场景）

**默认零 UI。** 满屏只有身体、地面、影子。

| 例外（允许常驻的元素） | 触发 | 理由 |
|---|---|---|
| 左下角 `物种名`，极低对比度 | 进场后 4 秒淡出，此后不再出现（`shell/notice.ts`，2026-09-13 落地） | 观众需要知道自己选的是什么，但只需要知道一次 |
| 演化进度：地面影子外缘的一圈极细弧线 | 常驻，但几乎看不见 | 它不是仪表，是"这个身体在积蓄什么"的暗示 |
| 左下角那块**实时读数**（`ui/readout.ts`，2026-09-14 落地） | 网页版常驻；**现场默认不挂**，要它就写 `?readout=on` | 这件作品的整条链是一具身体被一台机器**读**成数，而观众只看得见结果——于是那次翻译读起来像魔法，而"翻译一个人要付出什么代价"正是它的题目。这一块把那次翻译摊开：置信 / 关节 / 推理 Hz / 动能 / 舒展。**它只装测量，不装作品的决定**——乐章、进度、档位、忒修斯换到第几件一个都不上来（docs/40 §5、docs/23 §S5、docs/44 §7）。它是这一屏唯一一处允许有边框和圆角的东西，因为它必须读作**不是作品**；完整的 §F 论证在 `ui/readout.css` 的文件头 |
| 左上角「它有没有看见我」小屏幕（`ui/preview.ts`，2026-09-13 落地） | 网页版常驻；**现场默认不挂**，要它就写 `?preview=on`；`?demo=1` 永不挂 | 「默认零 UI」的前提是**它真的在动**。追踪垮掉时身体只是站着不动，而那和"作品坏了"在观众眼里是同一个画面 —— 这一块把那件看不见的事变成看得见的。它**顺利时一个字都没有**，所以它没有违反上面那条，它是那条规矩的前提条件 |

| 边界情况 | 表现 | 理由 |
|---|---|---|
| 追踪短暂丢失 < 1s | 保持最后姿态，加极轻微的 idle 漂移 | 完全静止会读成"卡了" |
| 追踪丢失 > 1s | 进 S7 溶解 | |
| 多人入镜 | 跟面积最大的那个。**切换目标时用 400ms 过渡**，不瞬移 | 瞬移会读成 bug |
| 观众太近（全身不入镜） | 地面上出现一条极细的位置线 + `往后一点`，2 秒后无论如何淡出 | 这是唯一一句功能性文案，必须短且会自己消失。**未实现**（2026-09-13 走查）：`COPY.live.stepBack` 写好了但没有调用点；"全身不入镜"的判定在 `stage/framing.ts`，那条线这轮不归 UI 动 |
| 观众背对 | 照常跟随（背面姿态一样能驱动） | 不做特殊处理 |
| 极端姿态（倒立/躺下） | 挂载数学已保证不产生 NaN；身体跟着倒 | 这是彩蛋不是 bug |
| 帧率跌破 45 | 自动降级：先关后期，再降实例上限，**不提示观众** | |
| 连续 30 帧渲染异常 | 回落占位几何；再失败则重载页面 | 观众看到的是身体变简单了，不是报错 |

## S5 · Evolve（升档瞬间）

不是独立场景，是 S4 里的**事件**。必须可感知，否则演化等于没发生。

- 时长 **600ms**：全身一次极轻的脉冲（亮度 +8%）+ 时间轻微停滞（0.15s 内 dt ×0.4）
- 变化的槽位**逐件**换装，最多同时 3 件，其余排队
- 同时一声低频确认音
- **没有文字、没有等级数字、没有 "LEVEL UP"**

| 边界情况 | 表现 |
|---|---|
| 阈值附近来回 | `tuning.ts` 的滞回 + 2 秒冷却挡住 |
| 一次要换 18 个槽位 | 排队播完（约 7 秒），期间观众仍可正常互动 |
| 降档 | **不做视听事件**。悄悄退回去 —— 失去不该被庆祝 |

## S6 · Slow loop（你的零件长出来）

作品的差异化时刻。全程 **只有一个 UI 元素**。

| 阶段 | 表现 |
|---|---|
| 触发（进场 20 秒后，每人一次） | 无提示。静默把剪影送出去 |
| 生成中（30–90s） | 身体的**某一个槽位**开始极缓慢地明灭 —— 就这一个信号 |
| 到货 | 该部件从骨轴外 0.15m 吸附回位 + 一声确认音 |
| 失败 | 明灭停止，恢复原状。**观众永远不知道失败过** |

延迟不是缺陷，是叙事：*它正在想怎么成为你*。所以**不要进度条、不要"生成中…"文案**——
那会把一个诗意的等待变成一次加载。

## S7 · Leave（离场 / 留念）

| 阶段 | 时长 | 表现 | 状态 |
|---|---|---|---|
| 溶解 | 2.5s | 身体散回粒子，落到地面 | 已实现（`presence` 的 LEAVING + creature/mass 的缩放） |
| 留念 | 6s | 屏幕下方：`物种名 · seed 码` + 一个小二维码 | **未实现**（2026-09-13 走查）：`COPY.leave.keepsake` / `COPY.leave.seed` 写好了，没有调用点。这是一整个功能，不是一处 UI 缺口 |
| 回落 | — | 粒子恢复呼吸，回 S1，换新 seed | 已实现（`presence.justReset`） |

| 边界情况 | 表现 |
|---|---|
| 溶解途中观众回来 | 取消溶解，回 S4，**保留 charge**（同一个人不该被清零） |
| 留念展示期间下一个人进场 | 立刻收起留念，进 S3。**不让新观众等** |
| 网页版 | 留念变成可点击的分享卡片，不是二维码 |
| 二维码服务不可用 | 只显示 seed 码。它本身就够复现那具身体 |

## S8 · 降级与错误（横切所有场景）

| 情况 | 观众看见 | 我们看见 |
|---|---|---|
| 任何一帧异常 | 什么都没有（上一帧继续） | 控制台一次（同消息只吼一次） |
| 连续 30 帧异常 | 身体变简单（占位几何） | 控制台明确的降级日志 |
| Act 连续 3 次异常 | 玩法悄悄换回 `follow` | 该 Act 被永久禁用 + 日志 |
| graphics context lost | 3 秒后自动重载 | 日志 |
| 摄像头权限被拒 | 网页：一个 `用我的摄像头` 按钮 + demo 回放照常演<br>现场：直接进 demo 回放 | `lastError` |
| 断网 | 完全无影响（慢回路静默关闭） | 日志一行 |

## S9 · 目录（网页版才有的那一个元素）

站点有**七**个可见面：`/`、`/about`、`/making.html`、`/passport.html`、
`/lineage.html`、`/dev/`、`/poster/*`。（`/lineage` 是后加的那一个，
它是唯一一个内容不由仓库决定、而由前面的观众决定的面。）
在这一节存在之前，**首页上一个入口都没有**，而且这些页面之间一条链接都没有 ——
一个评委打开首页，除非有人当面告诉他，否则永远不会知道 `/about` 和 `/making` 存在，
而那两页承载了这件作品一半的表达。

| | 规定 | 理由 |
|---|---|---|
| 位置 | **右上角** | 左上角已经被占了三次（`ui/page.ts` 的浮层页头、`?debug=1` 的 HUD、2026-09-13 起还有 `ui/preview.ts` 那块小屏幕，HUD 已为它让到 `top:224`）。右上角在所有页面上都是空的 |
| 收起态 | 一个词 + 一条细线：`目录 CONTENTS`。没有图标、没有汉堡 | 和入口层的 `.sb-act` 是同一个构件 |
| 展开态 | 一张表：名字 + **一句"它能回答什么问题"**，行间细横线，当前页标 `在这里` | 人不是在找功能，是带着疑问来的。`/dev/index.html` 已经验证过这个写法 |
| 语言 | 中英并置，不切换 | `src/ui/i18n.ts` 的设计决定 |
| 现场（`?kiosk=1`） | **根本不挂**。判断只有 `readFlags().nav` 一处 | 装置画面上不该有网站导航（§S4「默认零 UI」） |
| 满屏画布页 | 4 秒后淡到 0.18，鼠标碰上/键盘 tab 到就回来 | 和浮层页头同一条规矩、同一个数 |
| 文档流页面 | 常驻不淡出 | 那几页本来就是拿来读的 |
| 关掉 | `?nav=0` | 「投影但不是 kiosk」那种场合 |
| 入口展签之上 | 目录 z-index 11 > 展签 10 | 展签**就是网页版的首页**，目录不在这里等于不存在 |
| 当前页那一条 | 渲染成 `<span>` 而不是灰掉的 `<a>` | 一条点了什么都不会发生的链接，比没有链接更让人怀疑坏了 |
