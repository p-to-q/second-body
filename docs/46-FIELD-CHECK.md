# 46 · 现场检查表 —— 站上去十分钟，带回有用的反馈

> 2026-09-14。给**任何一个站到摄像头前的人**用：不需要读代码，不需要懂这件作品的来路。
> 照着走一遍，每一格填"是 / 否 / 说不清"，再加一句看到了什么。
> 数值的唯一来源是 `packages/core/src/tuning.ts`，这一页只是把它们翻译成"你会看到什么"。
>
> 为什么要这一页：这件作品最要紧的几条判断（五秒内认不认得出自己、第一次替换有没有被余光发现、
> 替换的声音像不像钟表），**没有任何一条测试能替人回答**。它们只能被一个站在前面的人回答，
> 而一句"感觉还行"带不回任何可以改的东西。

## 0 · 开始之前

| 要准备的 | 怎么做 |
|---|---|
| 地址 | 网页版：`https://useeme.ptoq.io/`；装置：`npm run kiosk` |
| 看得见机器在想什么 | 地址后面加 `?debug=1`：左上角出现调试读数（帧率、推理频率、弧线走到哪、忒修斯换到第几件） |
| 不想等三分钟 | 加 `&arc=60`：整条线压成一分钟。**只用来找问题**，节奏判断（像不像钟表）必须用正常的三分钟 |
| 想马上看到替换 | 加 `&theseus=6`：替换速度乘 6。同上，只用来找问题 |
| 一个人来回测 | 离开画面 **8 秒**以上，全部归零，下一次从头开始 |
| **关掉系统自带的自动取景** | macOS 控制中心 › 视频效果 › 人物居中（Center Stage）关；Windows 设置 › 相机 › Studio Effects › 自动取景关；不用 NVIDIA Broadcast 虚拟摄像头；云台摄像头关人脸跟踪。**检查**：站到画面一侧慢慢走，左上角小屏里的背景不该跟着动（docs/49 §5.6）。开着它，腿会在上游被裁掉，身体会一直是上半身的中景 |
| 看取景模式在想什么 | `?debug=1` 的 `framing` 两行：模式、为什么、待了几秒、膝踝几个在画里。坐近应该在 1 秒内变成 `upper`（镜头推近到上半身），往后退应该在 1 秒左右回到 `full` |

站的位置：离屏幕约 2.5 米，整个人（包括脚）在画面里。左上角小屏里骨架应该贴在你身上。

## 1 · 时间线：你会依次经历什么

整条线三分钟，**是一条连续的线，没有"切换"的那一刻**。下表的秒数是这条线上的地名，不是开关。

| 时间 | 应该发生 | 请留意 |
|---|---|---|
| 进场 | 左上小屏里骨架贴着你；物种名字出现 4 秒；左下角读数写着「有人」 | 名字是不是压在读数上面了（应该在读数**上方**） |
| 0–20 秒 | 纯镜像跟随，**一件零件都不换**。开场是人形，平涂加墨线，像一张画 | **五秒内会不会说"那是我"** —— 这是整件作品唯一的那个问题（docs/26 §E） |
| 20–40 秒 | 开始替换，先换锁骨、关节、脚这类不显眼的位置，每次一声很轻的响 | 第一次替换是被**余光**发现的，还是完全没注意到？（可能要到 40 秒前后才看得见 —— 第一段身体可能还没长出可替换的零件，这是已知的待观察点） |
| 40–85 秒 | 动作慢慢慢半拍（最多约 1.2 秒）；替换变快；借来的零件开始来自近亲物种 | 慢半拍是"它在回味"还是"卡了"？ |
| 85–135 秒 | 跟随变得有阻力、更圆；身体从人形漂向这个物种自己的形体；零件来自越来越远的物种 | 部分物种这里有约 25 秒两具身体重叠 —— **会不会卡顿** |
| 135–180 秒 | **只在你动的时候**它才慢慢转过来面向你；描边换成它自己的颜色；整体慢慢比你大或小约 6% | 转身是"它在看我"还是"它乱了"？ 大小变化有没有被余光感到？ |
| 3 分钟 | 18 个部位全部换过，一件原件都不剩，然后停住，不再升级 | 你还认得出这是"你的"动作吗？ |

**贯穿全程的四条**，每一条都可以当场验：

1. **挥一只手，它更可能换走那一侧。** 连续挥右手两三次，看被换掉的是不是右臂。
2. **动得多，替换更快**；但每一段有上限，不会一下子拆光。
3. **站着完全不动，它也停。** 永远不会自己表演。**如果它在你不动的时候自己动了，那是 bug，请记下时间。**
4. **每次替换**：旧零件碎成几颗墨点飞散、新零件长出来，**肢体的轮廓线不断**，同时一声轻响。

装置版独有：连续站满 20 秒，会送出一次你的剪影去生成一件零件；它可能在后半段出现在躯干上。

## 3 · 什么情况算坏了（请立刻记下时间）

- 你站着不动，它在动（违反"永远不脱钩"）。
- 离开 8 秒以上再回来，它不是从人形、从头开始。
- 某个部位突然变得很大或很小，和身体其余部分明显不成比例。
- 画面冻住、黑屏、或左上角调试读数里帧率长时间低于预算（`?debug=1` 下标红）。
- 左下角读数里的数在你离开画面后仍然在跳（应该变成破折号）。
