# assets/sound — 声音素材与授权

> 完整的声音设计见 `docs/29-SOUND.md`。这一份只管一件事：**这里的每一个文件从哪来、
> 谁做的、什么授权、我们动过它什么。** 字体那边已经这么较真了（`assets/fonts/`），
> 声音没有理由不一样。

## 现状：**四个文件，共 8.3KB**

四层**连续**声音仍然全部由 Web Audio 合成（`packages/app/src/sound/`），一个字节素材都没有。
新加的四个文件属于**第五层 · 离散接触音**（`sound/cues.ts`），
它们不是那四层的素材版，是另一类东西 —— 为什么这两件事不冲突，见下一节。
总量 8.3KB，离"不超过 3MB"还有 360 倍的余量。

## 为什么合成而不是下载（这是一次判断，不是偷懒）

去 freesound / archive.org 找 CC0 的 room tone 和 drone 是完全可行的，
也确实有大量可用素材（候选见文末）。不用它们，有四条各自独立的理由：

1. **素材是录下来的别处，合成是这里。** 一段录音里有它自己的房间、它自己的空调、
   它自己的那一天。这件作品的第一层要说的是"**这个**房间是活的"。
   借来的房间会和现场的房间打架 —— 而且观众听不出是为什么，只会觉得哪里不对。

2. **素材没有信号入口。** 这四层的全部意义是绑在 `Presence` / `MotionFeatures` /
   `tierChanged` / 慢回路 phase 上（PRD §3「因果可见」）。一段 wav 只能被
   调音量和调滤波；而合成的带通可以让**共振频率跟着物种走**、让带宽跟着玩法走。
   拿素材做同样的事，最后也是在素材上套一层合成处理 —— 那不如直接合成。

3. **23 个条目。** 名册还在长（docs/14）。每加一个物种就要有人去找一段新素材、
   记一次授权、再进一次 3MB 预算，这条流程一定会在某个物种上断掉。
   `SOUND.voice` 是从 `ThemeDef.axes` 推出来的，加物种不需要加任何东西。

4. **循环会被听出来。** 装置要连续跑 30 分钟以上（docs/00 §5）。
   一段 30 秒的底噪素材循环 60 次，站得久一点的观众一定能听出周期。
   合成的噪声用连续的滤波噪声 + 无循环相位的慢呼吸，没有周期可听。

## 为什么第五层反过来用素材（上面那四条**没有**被推翻）

上面四条论证的对象是**连续的氛围层**：一直在响的房间底噪、跟着速度走的身体噪声、
慢回路那段拍频。第五层是另一类东西 —— **离散的接触音**：观众伸手做了一件事，
一记，60–200ms，放完就没了。逐条对一遍，那四条**没有一条落在它身上**：

1. **"借来的房间会和现场的房间打架"** —— 只在声音**一直响着**的时候成立。
   一记 80ms 的敲击，它的尾巴短到根本来不及暴露自己的房间；
   而且我们把每一段的尾巴都掐掉了（见下表"我们做了什么处理"）。
   反过来，恰恰是一次**真实碰撞**里的那一千个微结构（初始接触的毛刺、
   材料的不均匀、手的偶然角度）合成补不出来 —— 合成的敲击听起来永远像
   "一个包络乘一段噪声"，因为它就是。

2. **"素材没有信号入口"** —— 第五层**不需要**信号入口，它绑的不是信号是**动作**。
   `SOUND.cues` 里能调的四个增益 + 一道低通就是它全部的表达，
   再多的连续调制对一记 80ms 的声音没有意义（观众来不及听见它在变）。

3. **"23 个条目，名册还在长"** —— 第五层与物种**无关**。
   这四记是界面的触感，不是身体的声音；加一个物种不需要加任何一个文件。
   文件数量是**封顶的四个**，而且刻意不满（升档、到货、自检、降级全都没有，
   理由在 `tuning.ts` 的 `SOUND.cues` 注释里）。

4. **"循环会被听出来"** —— 不循环。每一记是一次性的 `start()`，放完就断开。
   唯一会连着响的是"卡片经过"，那一条靠 `passMinGapMs` 节流、
   靠 `passDetune` 微抖播放速率、靠 `passRepeatDecay` 逐次变轻，
   所以一串滑动听起来是"渐远"，不是同一个采样连放十次。

一句话：**合成擅长连续，录音擅长接触。** 这不是立场反复，是分工。

**唯一一件合成做不了的事**（就连续层而言）：真实空间里那种复杂的早期反射（一个真正的大厅的"味道"）。
如果哪天现场需要那个味道，正确的做法是加**一段 CC0 的脉冲响应（IR）**
走 `ConvolverNode`，而不是换成素材播放 —— 一个 IR 是几十 KB，
而且它给所有四层同时上色，不用为每一层各找一段素材。那时就往下面这张表里加一行。

四条共同的事实，别在表里重复四遍：

- 拿的是 freesound CDN 上的 **ogg 预览件**（`cdn.freesound.org/previews/...`），不是原始 wav ——
  下载原始件要登录，而对一记 80–180ms、最后还要压成 64kbps opus 的接触音来说，
  预览件和原始件之间的差别听不出来。这一条写在这里，免得以后有人以为表里那个 URL 指的是原始件。
- 处理脚本不进仓库（和 `assets/raw/` 同一条规矩）。上面每一行的"做了什么处理"
  已经足够任何人从同一个 URL 重做一遍。
- 授权截图在 `licenses/<文件名>.png`，四张都是 2026-09-13 抓的。
  `vite.config.ts` 的 `shipAssets` 把 `licenses/` 排除在 dist 之外 ——
  素材本身 8.3KB，四张截图 660KB，让产物为观众永远不会加载的东西变大 80 倍是荒唐的。
- CC0 不要求署名。上表照样写了作者，理由见下一节第一条。

## 如果要加素材，规矩是

- **只收 CC0 / CC-BY / 公有领域。** CC-BY-NC 一概不收：这件作品可能会进有票务的
  展览，"非商业"那条线不由我们说了算，到时候再来清理素材是最糟的时机。
  CC0 在法律上不要求署名，但**这张表照样要写作者** —— 表是给我们自己看的，不是合规文书。
- **下载页面截个图**放在 `assets/sound/licenses/<文件名>.png`。
  素材站的页面会改、条目会被删，链接不等于证据。
- **总量不超过 3MB。** 超了就是删掉一个，不是"以后再压"（docs/02 P5）。
- 处理后的文件进仓库，**原始下载件不进**（和 `assets/raw/` 同一条规矩，docs/13 §2）。

## 查过的候选（留痕，不是采购单）

这一轮真去看过、确认授权可用、但**最终没有采用**的方向：

- **freesound.org** — 按 license 筛 `Creative Commons 0` 可以拿到大量 room tone /
  ambient drone。站方明确 CC0 条目可商用且不强制署名（部分作者在描述里请求署名，
  那是请求不是许可条件）。<https://freesound.org/>
- **archive.org** — 公有领域的现场录音与空间 IR。逐条目授权不一致，必须一条一条看。
  <https://archive.org/>
- **CC0 音效库（如 selektaudio 的 CC0 texture 集）** — 打包好的 drone / texture。
  <https://selektaudio.com/sound-lab/textures/drone>

采用其中任何一条**做连续层**之前，先回头读上面"为什么合成"的第 2 条：
**新素材要能接上一个已经存在的信号，否则它只是背景音乐。**
（离散接触音走的是另一条线，见"为什么第五层反过来用素材"。）

## 第五层这一轮试过、听过、**没要**的（留痕）

四记里每一记都不是第一个候选。下面这些是真下载了、真画了波形与频谱、
最后被否掉的，连同否掉的理由 —— 留在这里是为了**别有人回头再试一遍同一个坑**：

- **"陶瓷叮" 一类（freesound 209014 Ceramic Tink / 615308 Ceramic Cup Hit /
  668384 Glass Tap / 262958 Glass Tap）** —— 频谱能量挤在少数几个窄峰上
  （我们量的"窄峰能量占比"分别是 0.44 / 0.77 / 0.80 / 0.96）。
  那就是**一个音高**，也就是"叮！"。这件作品不要成功音。
- **木鱼 / 木块一类（262060 Woodblock Distance / 126481 / 508029）** ——
  干净的单次指数衰减，但周期性极强，听起来是一件**乐器**被敲了一下。
  乐器有调性，调性有情绪，那不是"一次接触"。
- **多记混在一条里的（611501 perc\_woodenfrog 是五记刮奏、371370 / 179997 的马克杯是双击、
  398489 粉笔与 215346 铅笔在 120ms 后各自还有第二下）** ——
  波形上一眼看得见第二个起音。一个动作配一记，配出两记就是在说"发生了两件事"。
- **尾巴不收的（275679 wooden rods、756421 Ceramic Lid）** ——
  截到 70ms 之后仍有一层不衰减的底噪（录音现场的房间）。
  它正好是"为什么合成"第 1 条说的那件事：别人的房间跟着素材一起进来了。
- **能量往上走的（470189 Sliding Paper、496189 Clothing impact、858468 Flipping Page
  Forward）** —— 包络在后半段才到峰值。**上扬 = 成就感**，
  而"确认选中"不是成就；"经过"更不是。
- **塑料 / UI 一类（734219 PlasticMouseClick、575457 Tap Android、342200 Videogame
  Menu BUTTON CLICK）** —— 材质就不对。这件作品的物种是瓷、纸、绒毛、金属。
